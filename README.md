# Self-Care Toolkit AI Assistant

A personalized self-care recommendation web application that uses AI to generate customized wellness activities based on your current mood, struggles, and preferences.

## Features

- **Interactive Quiz Interface**: Step-by-step questionnaire to understand your needs
- **AI-Powered Recommendations**: Uses OpenAI's GPT-5-nano to generate personalized self-care activities
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Beautiful UI**: Modern, welcoming design with purple gradient theme
- **Real-time Loading States**: ChatGPT-style loading indicators for better UX
- **Flexible Navigation**: Easy quiz restart and home navigation options

## How It Works

1. **Welcome Screen**: Click "Get Started" to begin
2. **Quiz Questions**: Answer 5 questions about:
   - What you're struggling with
   - Your current mood
   - What you're looking for
   - Your coping preferences
   - Your energy level
3. **AI Processing**: The system generates personalized recommendations
4. **Results**: View 3 customized self-care activities with:
   - Activity title and description
   - Why it helps
   - Step-by-step instructions
   - Time estimate and difficulty level

## Technical Stack

- **Backend**: Python Flask
- **AI Integration**: OpenAI GPT-5-nano API
- **Frontend**: HTML5, CSS3, JavaScript
- **Styling**: Custom CSS with Flexbox and responsive design
- **Environment Management**: python-dotenv
